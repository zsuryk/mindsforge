# Transcription provider is explicit, not a fallback

Transcription runs through one of two providers — Groq's hosted Whisper (`groq`, the default) or a local faster-whisper model (`local`) — selected explicitly via `TRANSCRIPTION_PROVIDER`; there is no automatic fallback. A fallback would silently swap engines when a Groq key is missing or the API errors, making results and CPU usage unpredictable, so the choice stays visible and deliberate. The local provider exists so Groq-unavailable regions need no VPN: it runs faster-whisper (CTranslate2, CPU `int8`, `small` model by default) rather than openai-whisper (PyTorch-heavy) or whisper.cpp (needs a compiled binary), loading the model lazily and caching it per process. First use downloads the model to the Hugging Face cache; after that it runs fully offline. Failure semantics are fail-closed in both providers — a missing key or failed model/API call fails the job with a descriptive message.
