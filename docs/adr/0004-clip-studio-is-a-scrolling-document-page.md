# Clip studio is a scrolling document page, not a fixed-viewport workbench

The clip studio page scrolls like a normal document: the video and transcript sit in a main column, a sticky rail (virality score + platform hooks) pins alongside, and the adaptation studio follows in the same column. We deliberately rejected a Descript/CapCut-style fixed-viewport shell — a full-screen workbench where each pane scrolls independently. Despite the name "studio", the page is a review-and-act flow in a dashboard app: transcripts are bounded (clips run 15–60s, roughly 30–200 words), the adaptation studio is content-heavy (feature panels, assets, publish checklist) and wants page flow, and document flow stays accessible and mobile-friendly. Long content is handled by capping panes with internal scroll (the transcript gets a max-height with overflow-y-auto and a bottom fade) rather than by freezing the viewport; that cap plus the sticky rail keeps the layout consistent regardless of transcript length.
